1. Interface Swagger de l'API DataServ

L'API REST de DataServ est entièrement documentée grâce à Swagger UI, accessible à l'adresse http://localhost:3001/api/docs. Cette documentation interactive est générée automatiquement par le module @nestjs/swagger à partir des décorateurs TypeScript présents dans le code source. Elle permet de tester chaque endpoint directement depuis le navigateur, en fournissant un token JWT via le mécanisme Bearer Auth.

http://localhost:3001/api/docs

3. Liste des Tickets avec Filtres

La page de gestion des tickets présente l'ensemble des tickets sous forme de tableau paginé avec un système de filtres multi-critères. Les statuts sont distingués visuellement par un code couleur cohérent sur toute l'application. L'accès est filtré automatiquement selon le rôle : un technicien ne voit que ses tickets assignés, un client ne voit que ses propres tickets.

6. Formulaire de Clôture d'Intervention

La clôture d'une intervention est une étape critique du processus métier. Elle déclenche la mise à jour du statut du ticket en CLOTURE, l'enregistrement des heures travaillées et du temps de déplacement (qui impactent le solde contractuel du client), ainsi que la génération optionnelle d'un rapport PDF envoyable au client.
