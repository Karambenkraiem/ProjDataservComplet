2. Approche de Test

Tous les tests sont de type unitaire : chaque service est testé de manière isolée en remplaçant ses dépendances (PrismaService, JwtService, bcrypt) par des mocks Jest. Aucune connexion à une base de données n'est requise.

Dépendance mockée Raison
PrismaService Évite toute connexion PostgreSQL — les appels DB sont simulés via jest.fn()
JwtService Retourne un token statique 'mock_token' pour vérifier les appels sans cryptographie réelle
bcrypt.compare / bcrypt.hash Contrôle précis du résultat (succès ou échec) sans calcul de hash coûteux
